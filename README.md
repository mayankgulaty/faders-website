# Faders website

The product site for [Faders](https://github.com/mayankgulaty/faders), the radio app that doesn’t suck.

Static HTML, CSS and JS: no build step. Open `index.html`, or serve the folder (`python3 -m http.server`).

- `index.html` – the product page (hero, film, sticky feature story, moods, iPhone Duo unfold, devices, privacy, pricing)
- `support.html`, `privacy.html` – support and privacy policy
- `main.js` – scroll reveals, sticky story, Duo unfold, ambient colour, film. **Set `LIVE = true`** once Faders is on the App Store to turn the “Coming soon” buttons into App Store links.
- `assets/` – web-sized captures from the app, icon, promo film, social image (`og.png`)

Hosted with GitHub Pages from `main`.
